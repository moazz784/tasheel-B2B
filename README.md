# مدى للسفر والسياحة

واجهة عربية متجاوبة لرحلات العمرة والحج والسياحة، مبنية باستخدام React وVite وReact Router.

## التشغيل

```sh
npm install
npm run dev
```

لإنشاء نسخة الإنتاج وتشغيل فحص lint:

```sh
npm run build
npm run lint
```

## الباقات

بيانات الباقات التجريبية موحّدة في `src/data/packages.js`. حدّث هذه البيانات عند ربط مصدر بيانات فعلي؛ لا يوجد backend أو قاعدة بيانات في هذا الإصدار.

تدعم الواجهة استعراض باقات العمرة والحج والسياحة، البحث والتصفية والترتيب، وصفحة تفاصيل مشتركة لكل باقة.

## إعداد واتساب

رقم واتساب وصياغة رسائل الاستفسار مركزان في `src/config/whatsapp.js`. أنشئ ملف `.env.local` في جذر المشروع وأضف رقم واتساب للأعمال بصيغة دولية، أرقام فقط مع رمز الدولة وبدون علامة `+`:

```env
VITE_WHATSAPP_NUMBER=
```

أعد تشغيل خادم Vite بعد تغيير متغيرات البيئة. تفتح الروابط عبر `wa.me` في تبويب جديد، ويستكمل نموذج الاستفسار رسالة الباقة ببيانات العميل. إذا لم يُضبط الرقم، يمكن للعميل إنشاء الرسالة ونسخها لإرسالها يدوياً؛ لا يُستخدم رقم تجريبي ولا يُؤكد أي حجز تلقائياً.

روابط الحسابات الاجتماعية اختيارية، وتُضبط باستخدام `VITE_INSTAGRAM_URL` و`VITE_X_URL` و`VITE_SNAPCHAT_URL`.
